# Referee requests

If you believe the referee (`eval/`), `AGENTS.md`, a role prompt or `docs/BRIEF.md` is wrong,
write it here and stop. The owner decides, and changes them only through a PR labelled
`referee-change`.

```
## R-### · YYYY-MM-DD · <agent/model>
What is wrong: …
Evidence: …
Proposed change: …
Status: open | accepted | declined
```
